The Challenge

Pivot to Talenzap: Overcoming Domain Constraints & Rebuilding Identity

When domain availability constraints prevented the reservation of the original brand name "Arenastars," the team executed a strategic pivot to "Talenzap." Beyond a simple name change, the challenge required designing an adaptable visual system that could seamlessly transition across mobile UI, interactive digital touchpoints, high-contrast dark modes, and physical brand collateral under a bold new unified tagline.

“Your Stage to Win.”

Strategic Pillars

Adaptive Rebranding

Transitioning from Arenastars to Talenzap while keeping core audience engagement and energy intact.

Interconnected Mark

A dynamic "T" emblem with forward-moving geometric forms symbolizing growth, motion, and competition.

High-Contrast Aesthetic

Pairing vibrant Coral Red with Deep Charcoal and Crisp White for maximum visual impact across digital screens.

Flexible System Integrity

Clear typography hierarchies and interactive UI rules built for scalable app components and developer handoffs.

Visual Identity

Crafting the Visual System

The new identity centers around a modern geometric emblem built on precise grids. Paired with the highly legible Nunito Sans type family, ranging from Bold headings to Regular body prose, the brand system provides structural clarity across mobile interfaces, dashboard layouts, and promotional graphics.

Implementation

Digital & Physical Ecosystem: UI/UX Change Requests (CR) Implementation

I directly led and executed targeted UI/UX Change Requests (CR) across key touchpoints within both the User Module and Admin Module. This involved refining user flows, improving interface component consistency, and updating visual hierarchy to seamlessly adapt the system from Arenastars to the new Talenzap design system.

4.1 User Module CR Enhancements

  • Interactive Screen Optimizations: Overhauled core mobile app flows and primary navigation screens to ensure frictionless user journeys during live talent streams and gaming events.
  • Component Refinement: Implemented high-contrast CTA states, interactive buttons, and responsive cards utilizing the refreshed Talenzap palette for maximum visual clarity on mobile interfaces.

4.2 Admin Module CR Enhancements

  • Dashboard Data Hierarchy: Structured scalable layouts for administrative controls, content management, and user moderation panels using strict Nunito Sans typography hierarchies.
  • System Consistency: Enforced precise spacing, grid alignments, and component states across dense admin tables and action screens to streamline backend workflows for platform operators.

4.3 Physical Applications & Brand Rules

  • Spatial & Merchandise Presence: Applied the updated emblem and typographic rules across physical collateral, apparel, and signage mockups.
  • Brand Integrity Standards: Defined explicit "Logo Don'ts", minimum clearance boundaries, and color usage guidelines to maintain visual consistency across all third-party integrations and physical touchpoints.
